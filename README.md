# 니가타 설국 여행 (2026.12.10–12.13)

일행 4명이 함께 쓰는 여행 가이드 웹앱이에요. 폰에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

- **일정**: 날짜별 타임라인, 구글맵·길찾기
- **예약**: 항공·숙소·렌터카 정보, 바우처 사진 보관함
- **가계부**: 원화·엔화 지출, 더치페이 정산
- **사진**: 날짜별 포토로그
- **준비**: 출발 전 체크리스트, Visit Japan Web QR, 스키·운전 안내

## 구조
- 화면: `index.html`, `css/`, `js/app.js`
- 공개 일정 데이터: `js/itinerary.js`
- 예약번호·이름·바우처·가계부·사진·체크리스트: **Firebase Firestore** (로그인한 일행만 읽고 쓸 수 있음)
- 접근 규칙: `firestore.rules.example`을 참고해 Firebase 콘솔에서 설정 (실제 이메일은 저장소에 올리지 않음)
- 오프라인: `sw.js`, `manifest.webmanifest`

## 홈 화면에 추가
- 아이폰(사파리): 공유 버튼 → **홈 화면에 추가**
- 안드로이드(크롬): ⋮ 메뉴 → **앱 설치** 또는 **홈 화면에 추가**
